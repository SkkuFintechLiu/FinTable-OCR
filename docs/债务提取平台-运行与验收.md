## 目标与口径

- 目标：从债券年度报告/募集说明书 PDF 中抽取“发行人合并口径有息债务结构情况”
- 年度口径：仅使用年度/年末/截至 12/31 口径（若报告口径不同需人工确认）
- 标准字段：信用类债券、银行贷款、非银行金融机构贷款、其他有息债务、合计、1年以内

## 运行方式

### 本地运行

```bash
python app.py
```

默认访问：`http://127.0.0.1:5000/`

### Docker 部署

```bash
docker compose up --build
```

访问：`http://localhost:5000/`

## 页面使用

- 上传 PDF：拖拽或点击选择（单次最多 50 个）
- 处理队列：查看每份文件的类型/发行人/年份/状态，并可改类型重跑
- 数据预览：汇总宽表；可直接编辑单元格并自动保存
- 导出：导出 Excel（含汇总数据与追溯信息）

## 验收点（建议）

- 标题必须命中：发行人合并口径有息债务结构情况
- 年份：必须为目标年度（2024/2025 等），避免误用其他年份段落
- 单位：统一为“亿元”输出（如果报告单位为万元/元，系统会自动换算）
- 可追溯：每个年度至少能在 trace 中看到页码与命中标题文本

## 常见问题

- 扫描件识别慢：已限制并发与 OCR 预算；建议一次不要同时解析太多扫描件
- 某些 PDF “未找到表/可信度低”：通常是报告结构差异或标题相似段落干扰，需要进一步补规则或人工校对
